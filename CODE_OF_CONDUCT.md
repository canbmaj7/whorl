# Code of Conduct

We want Whorl to be a friendly, useful place for people at every experience level.

**Expected:** be respectful, assume good faith, give specific and kind feedback, credit other people's work, and say so when you are unsure.

**Not acceptable:** harassment, personal attacks, discrimination, sharing other people's private information, pasting fingerprint data or secrets, or deliberately misleading hardware reports.

Maintainers may edit or remove comments, issues and contributions that break these rules, and may block repeat offenders. To report a problem, contact the maintainers through a private GitHub security advisory or the contact on the maintainer's GitHub profile.

This is a short adaptation of the spirit of the Contributor Covenant (https://www.contributor-covenant.org/).
